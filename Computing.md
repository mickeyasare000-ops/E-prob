### WHAT IS A COMPUTER?
A computer is an electronic device that takes raw data as input,processes it with th help of the _CPU_ and brings out the results in soft or hardcopd form which can be stored for future use.

### CLASSIFICATIONS OF COMPUTERS :
Computers are classified based on size.
* **Microcomputers**: 
These are the smallest and are designed for personal purposes only. some examples are smartphones and desktop computers.
* **Minicomputers**: These are  mid-sized computers designed for businesses purposes. Examples are servers.
* **Mainframe Computers:** This type of computer is used by large organisations and is mostly used for processing data in bulk.
* **Super Computers:** These are the largest and most powerful. They are mostly used for researching purposes and also performing complex calculations. 
### COMPUTERS BASED ON PROCESSING POWER
* **Wearable Computers:** These are computers that can be placed on part of the body such as **smart watches, body trackers,watches.

* **Microcomputers:** These types of computers were purposely created for personal use so has the lowest processing power as compared to the rest.
* **Servers:** This type of is designed to provide services for multiple users so it is a bit faster than the microcomputers.
* **Mainframe:** Mainframe computers are computers designed to handle a lot of data and since they are required in large organisations,they require high processing power and speed.
* **Supercomputers:** They are the fastest due to the complex calculations they are used to perform.

A software is a set of instructions that tells a computer to perform a task, when to perform the task and how to perform the task. **For example** when i take the calculator app and i want to add two numbers x+y, the software tells the computer that take the first number and add it to the next one and bring out the output. ### HARDWARE:
Hardware refers to the physical components of a computer that can be touched. It includes all the devices and machinery required to make a computer function. In other words, the hardware performs the information processing cycle.Hardware components are grouped into four namely: input,processing output and storage devices.
1. _Input Devices:_  
These are devices used to enter instructions into the computer **Some examples are** mouse, keyboard,etc.
1. _Processing devices:_ 
These are devices which help to convert raw data into meaningful information. This is mostly performed by the CPU.
1. _Output devices:_
These are devices used to display processed information onto the computer in either hardcopy or softcopy format  **Some examples are** printers,monitors and many others.
1. _Storage DEVICES :_  
Helps to store information permanently.**Some examples are** Hard disk drives and Solid State drives. 


### INTERACTIONS BETWEEN SOFTWARE AND HARDWARE
The software and the hardware moves hand in hand meaning without the software, the hardware cannot perform its function.To understand this lets take this **Eample:** when I want to input the letter **Z** I need my keyboard (**hardware**) to send the information to the software. The software then processes it into machine-readable language that the CPU can understand and then with the help of the monitor whic will help display the information proceesed.

1. _Random Access Memory:_

1. _Graphics Card (GPU):_

1. _Power Supply:_  
The power supply helps to produce power to all parts of the computer.
1. _ Cooling Fan:_  
The cooling fan helps to prevent components from overheating.

## THE CPU AND ITS FUNCTION
The CPU consists of three units namely: the _memory unit, control unit and arithmetic logic unit.
** ITS FUNCTION:
When data is being inputed into the computer, it first moves to the memory unit and the control unit gets instructions from the memory unit to determine what to do with the input and then transfers it to the ALU. The function of the **ALU** is to perform mathematical operations like: addition, subtraction,multiplication and division. After that, it is sent t the memory and then providing feedback as output. 

## TYPES OF CPU
* _Single Core CPU:_ Usually used in the 1970s and can perform only one function or task at a time.
* _Dual Core CPU:_ Has two cores so it can handle two task at once.
* _Quad Core CPU:_ Has four cores making it good for heavy multitasking activities like editing and playing modern games.
## HOW CPUs MAKE COMPUTERS FAST 
* Many CPUs have multiple cores which help the computer to worl on different taskes at the same time.
* The clock speed measured in GHz determines how many instructuins the computer can handle per second.

## MEMORY
Memory is an electronic storage place where imformation are being stored and without it the computer will not operate correctly.
### TYPES OF COMPUTER MEMORY 
* **Primary Memory**
Primary memory stores information for a short period of time.
1. **Random Access Memory**
Stores information only when the computer is running or active. RAM is divided into two ** SRAM and DRAM.**
_SRAM (Static RAM):_
Uses transistors to store information continiously without refreshing it. It is extremely fast and expensive.
_Dynamic RAM (DRAM):_
Uses capacitors to store data and needs to be refreshed a thousand times. It is usually cheeper.
2. **ROM**
Read Only Memory helps to store information permanently or for a long period of time. It has four main types namely: PROM,EPROM,EEPROM and MROM. 

* **Secondary Memory**
Secondary memory also known as the auxillary memory which helps to store information permanently or for a long period of time even when there is no power. The CPU can access its memory only if it is being transferred to the main memory. ** TYPES OF SECONDARY MEMORY IS : magnetic tape,magnetic disk and optical discs.
